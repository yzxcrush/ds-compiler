🧠 AI 训练教程 · 让别的 AI 学会 Ds

0. 原理：三件套

让 AI 学会 Ds，光有提示词不够，需要「可检索的上下文 + 可训练的数据 + 可执行的评测」。下面每一步都能在手机上直接复制链接或命令。

1. 给模型喂上下文（RAG / 提示词）

llms.txtAI 入口索引打开
LANGUAGE_CARD.md5k token 语言卡打开
llms-full.txt约 162 KB 全量上下文打开
spec/DS-v0.1.md完整规范打开

推荐：把 system_prompt.txt 作为 system，再附语言卡；需要细节时再检索规范对应章节。

你是 Ds v0.1 专家。优先用 0.1c 精简写法：不需要 package / fn main，顶层语句即入口；
fn f(a,b)=a+b；for i in 0..10: ...；x=1 即不可变定义，可变用 var；支持 += 等复合赋值；f"{x}" 插值。
不要编造关键字；生成后用 dscc --check 验证。

2. 用现成数据微调

ds_sft.jsonl41 条 chat 指令打开
ds_corpus.jsonl10 篇语料打开
ds_bench.jsonl25 个评测任务打开

建议先用 LoRA 小规模微调（Qwen / Llama 7B 级），再用评测集验收；数据格式为 OpenAI/Anthropic 兼容的 messages。

# 示例：加载 SFT 数据（在电脑上）
import json
rows = [json.loads(l) for l in open("ds_sft.jsonl", encoding="utf-8")]
# rows[i]["messages"] 可直接喂给 TRL / LLaMA-Factory 等 chat 训练

3. 评测：判断 AI 真的学会了

让模型对 ds_bench.jsonl 的 prompt 生成完整 Ds 程序，保存为 {"id":"fib","code":"..."} 每行一条，然后：

python3 tools/ds_bench.py --submissions sub.jsonl --json result.json
# 输出：每个任务的 PASS/FAIL 与总分；--strict 可用于 CI

4. 生成 → 执行 → 修正（工具闭环）

让 Agent 把编译驱动当工具用：dscc file.ds --check 只做解析检查，dscc file.ds 解释执行。生成的代码先 check 再运行，错误定位精确到行列。

5. 注意

  • Ds 0.1 是定义稿：不要向模型宣称 class/match/try 在所有实现都可用。
  • 不要混用其他语言语法（struct、let mut、<T> 泛型、-> 当 lambda 都是错的）。
